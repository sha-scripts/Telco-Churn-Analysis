# Telco Customer Churn Analysis
Analyzed churn patterns for a telecom company using SQL, Python, and Power BI.
- Data: Telco Customer Churn dataset (7,043 customers).
- Tools: SQLite (queries), Python (EDA), Power BI (dashboard).
- Key Findings: 42.7% churn for month-to-month, 45.3% for electronic check, higher churn in first year.
- Recommendation: Incentivize longer contracts and streamline payments.
